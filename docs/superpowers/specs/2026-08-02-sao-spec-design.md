# eソードアート・オンライン アリシゼーション-夜空- ロジック設計

## スコープ

`logic.js`（純粋な確率・状態遷移ロジック）と、node:testによるユニットテストのみを作成する。index.html/script.js/style.cssなどUI一式はフォーマット確定後に別途着手する。

## 台の基本スペック

| 項目 | 値 |
|---|---|
| 大当り確率（通常時） | 1/199.9 |
| 大当り確率（RUSH中：SR/WoU共通） | 1/51.6 |
| RUSH突入率 | 50% |
| SR（SWORD RUSH）継続率 | 約65% |
| WoU（War of Underworld）継続率 | 約75% |
| 時短回転数 | 0回 / 53回 / 70回 |

## ①通常時の抽選

毎回転 `1/199.9` でヒット判定。ヒット時は単発の累積バケット抽選で以下に分岐:

| 当選内容 | 割合 | 時短 | 移行先 | 払出 |
|---|---|---|---|---|
| ぼくの英雄 | 1.5% | 70回 | WoU直行 | ソードドライブ演出（先付け1500） |
| 2R（成功） | 48.5% | 53回 | SR突入 | 300個 |
| 2R（失敗） | 50.0% | 0回 | 通常継続 | 300個 |

## ②SR中の抽選

毎回転 `1/51.6` でヒット判定。ヒット時は単発の累積バケット抽選で以下に分岐:

| 当選内容 | 割合 | 時短 | 移行先 | 払出 |
|---|---|---|---|---|
| 10R（決意の刃なし） | 45.0% | 53回 | SR継続 | 1,500個 |
| 10R（決意の刃・失敗） | 33.0% | 53回 | SR継続 | 1,500個 |
| 10R（決意の刃・成功） | 11.0% | 70回 | WoU移行 | 1,500個 |
| 咲け、花たち（決意の刃・成功） | 11.0% | 70回 | WoU移行 | ソードドライブ演出（先付け1500） |

## ③WoU中の抽選

毎回転 `1/51.6` でヒット判定。ハズレ当り（時短なし）は存在しない。ヒット時は単発の累積バケット抽選で以下に分岐:

| 当選内容 | 割合 | 時短 | 払出 |
|---|---|---|---|
| 10R | 60.0% | 70回・WoU継続 | 1,500個 |
| 神器解放SWORD DRIVE | 40.0% | 70回・WoU継続 | ソードドライブ演出（先付けなし） |

## ④ソードドライブ演出（共通内部ロジック）

1,500個確定後、排他的に2ルートへ:

- **ルートA（97.5%）**: 保留4個を1個ずつ`1/2.17`で抽選。当選数0〜4個に応じて`先付け + 1500×当選数`（4個時のみ上乗せ分岐なし、7,500個で確定）。
- **ルートB（2.5%）**: 保留消化を経由せず、1.5%で`先付け+3000`確定、1.0%で`先付け + resolveSwordDrive(0)`（再帰でもう一回）。

## アーキテクチャ

- `logic.js`: `'use strict'` + `module.exports`、ghoul版の規約を踏襲
  - 確率定数: `P_NORMAL_HIT = 1/199.9`, `P_RUSH_HIT = 1/51.6`
  - `spinNormal()` / `spinSr()` / `spinWou()`: ヒット判定→ヒット時のみtype抽選（ghoul版`rollRushHitType`と同じ「1回のhit判定→1回のtype抽選」パターン）
  - `resolveSwordDrive(precedingBonus)`: 再帰関数。ルートB分岐→さらに再帰、ルートA→保留4個ループ
  - `applySpin(state)`: `{ mode: 'normal'|'sr'|'wou', jitanRemaining: number }` を受け取り、現在modeに応じたspin関数を呼び、新state・outcome種別・払出個数を返すイミュータブルな遷移関数（ghoul版`applyRushSpin`と同型）
- `test/logic.test.js`: `withMockRandom`ヘルパー（ghoul版から移植）でMath.randomを固定し、各確率境界・状態遷移・ソードドライブの再帰分岐（ルートA全パターン、ルートB両分岐、再帰時の合算）を網羅
- `package.json`: `"test": "node --test \"test/**/*.test.js\""`（ghoul版と同一）
